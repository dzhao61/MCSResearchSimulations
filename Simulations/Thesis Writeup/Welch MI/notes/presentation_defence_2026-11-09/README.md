# Presentation defence guide

The 13-page PDF explains the current 13-slide main talk and all 14 backups.
It provides spoken answers, deeper mathematical explanations, interpretation
of figures and numerical examples, scope boundaries, and a rehearsal route.
It incorporates the latest population-based/sample-based labels and colour
mapping on Slides 7-8. The presentation itself was not modified by this task.

The guide is a standalone LaTeX document with preamble.tex. Build with
pdflatex twice using job name Daniel_Zhao_Welch_MI_Presentation_Defence_Guide.
No main-thesis build, publication hook, commit, or push is involved.
Scientific and layout checks are recorded privately in verification.json.
