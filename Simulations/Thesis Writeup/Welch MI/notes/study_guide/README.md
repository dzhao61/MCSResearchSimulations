# Compact Welch MI study guide

The seven-page PDF is a personal familiarisation and presentation guide based
on the original signed main thesis, including its original Chapter 4.
It covers all chapters and both appendices, with additional explanation of
g, tau, and the degrees-of-freedom calculation. The numerical g/tau example
is explicitly illustrative. Printed thesis page references aid follow-up.

The accompanying LaTeX source is standalone. Build it with pdflatex twice,
using the job name Daniel_Zhao_Welch_MI_Study_Guide. This guide has no
main-thesis packaging or publication hook. The main thesis and both signed
submission copies remain unchanged. Verification details are recorded in
verification.json.
