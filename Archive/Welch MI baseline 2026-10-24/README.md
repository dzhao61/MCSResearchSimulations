This directory preserves the complete previous baseline from before the
redesign became the main version. It contains the original folders at
their original relative paths:

- `Thesis Writeup/Welch MI/`: manuscript sources, PDFs, delivery files and historical drafts.
- `WelchSatterthwaiteMI/`: experiment code and all saved evidence.

All 30,042 original files were verified against `ORIGINAL_FILES_SHA256.json`
before relocation. The four directories were moved together without
changing their contents. Existing instructions inside them refer to their
former locations. Preserve this archive; use the promoted project at the
Simulations workspace root for current work.
