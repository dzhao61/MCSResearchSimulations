# Differential MI Welch-Type Article

This directory contains the journal-style methods article for the
bias-corrected Welch-Satterthwaite approach to comparing mutual information
between two independent discrete populations.

## Main Files

- `main.tex`: manuscript source
- `main.pdf`: compiled journal-style article
- `references.bib`: BibTeX bibliography
- `figures/`: publication figures used by the manuscript
- `make_figures.py`: regenerates the result-summary figures from frozen outputs

## Build

From this directory:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

If TeX Live is installed on macOS but is not on `PATH`:

```bash
PATH=/Library/TeX/texbin:$PATH \
  latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

## Regenerate Figures

From the repository root:

```bash
MPLBACKEND=Agg MPLCONFIGDIR=$PWD/.mplcache XDG_CACHE_HOME=$PWD/.cache \
  .venv/bin/python WelchSatterthwaiteMI/article/make_figures.py
```

The calibration image copied into `figures/` is generated by the decisive
validation runner. The remaining article figures are generated directly by
`make_figures.py` from the frozen aggregate result files.

The manuscript distinguishes the frozen BCW-DMI experiment from the later
post-hoc variance-functional audit. Reproduce that audit from the repository
root with:

```bash
.venv/bin/python WelchSatterthwaiteMI/experiments/audit_variance_bias.py \
  --output-dir WelchSatterthwaiteMI/results/variance_bias_audit
```
