# Welch MI research

This repository is rooted at `Research/`. The scientific workspace and
presentation remain in their existing folders.

| Folder | Purpose |
| --- | --- |
| [Simulations](Simulations/) | Active thesis, estimator code, experiments, and saved evidence. |
| [Thesis Presentation](Thesis%20Presentation/) | Current presentation, speaker notes, assets, and earlier versions. |

The current thesis source is
`Simulations/Thesis Writeup/Welch MI/main.tex`. Its named delivery files are
in that thesis folder's `deliverables/` directory. The current presentation
is `Thesis Presentation/Daniel_Zhao_Welch_MI_Presentation.pptx`.

Read [the scientific workspace instructions](Simulations/AGENTS.md) before
working on the thesis or experiments. The existing numerical environment
remains at `Simulations/.venv/`.

To rebuild the thesis, run the existing packaging command from the thesis
folder. Requested main builds retain the scoped automatic commit-and-push
workflow. Other Research folders, including submission copies, remain local
under the root ignore rules.

The repository root moved from `Simulations/` to `Research/` on
8 November 2026. The migration preserves the existing commits, branches,
remotes, linked worktree, and physical scientific-project paths. Existing
tracked paths now have a `Simulations/` prefix.
