\chapter{Reproducibility and Protocol Record}
\label{app:reproducibility}

The final protocol is
\path{WelchSatterthwaiteMI/experiments/THESIS_REDESIGN_PROTOCOL.json},
version 1.0.0, frozen on 7 September 2026 UTC before the final simulation.
It specifies the population grids, seeds, methods, 20,000 replicates,
\(\alpha=0.05\), validation tolerances and timing design. This local freeze
followed exploratory development; it was not an external preregistration.

The run contains 3,111 unique configurations, 4,001 display positions and
534 population pairs, corresponding to 62,220,000 sampled table pairs.
The saved verification records check the population targets, result
denominators, paired method outputs, validity rules and supplementary
results report.
Chapter~\ref{chap:results} uses the same frozen tables; no population was
resimulated for a thesis figure.

The software requires matching table shapes, at least two rows and columns,
finite nonnegative integer counts, and more than one observation in each
table. Wald requires a finite corrected difference and standard error,
\(\Vhat(P)+\Vhat(Q)>10^{-14}\), and a finite p-value. Expanded Welch also
requires positive finite component and combined degrees of freedom and a
finite p-value. It does not calculate a combined degree of freedom when a
component degenerates, even if the direct combined expression in
Appendix~\ref{app:derivation-details} has a value. Failed conditions are
recorded as invalid calculations.

The exact software versions, seeds and source hashes are recorded in
\path{WelchSatterthwaiteMI/results/thesis_redesign/run_metadata.json}.
The experiment supplement contains the protocol, implementation, consolidated
results, 3,111 configuration checkpoints, supplementary results report, mechanism diagnostics
and tests. Its README documents minor post-run orchestration changes; the
frozen population construction, simulation and method calculations are
unchanged.

The evidence audit reconstructs the protocol manifests and checks every figure
and Chapter~\ref{chap:results} claim against the saved files. Final checksums
are in \texttt{SHA256SUMS.txt}. After extracting the source and supplement into
one archive root, run these commands from the directory containing
\texttt{main.tex} and \texttt{WelchSatterthwaiteMI/}:
\begin{quote}
\small\raggedright
\texttt{python} \path{figures_rewrite/make_figures.py}\par
\texttt{python} \path{figures_rewrite/audit_evidence.py}\par
\texttt{latexmk -pdf main.tex}
\end{quote}
