\chapter{Reproducibility and Protocol Record}
\label{app:reproducibility}

The final statistical protocol is
\path{WelchSatterthwaiteMI/experiments/THESIS_REDESIGN_PROTOCOL.json},
version 1.0.0, frozen on 7 September 2026 UTC before the final simulation.
It specifies the population grids, seeds, methods, 20,000 replicates,
\(\alpha=0.05\), validation tolerances and timing design. It is a local
protocol freeze following exploratory work, not an externally registered
analysis plan.

The run metadata report 3,111 unique configurations, 4,001 display slots,
534 population pairs, 62,220,000 sampled table pairs and 124,440,000 method
evaluations. The timing experiment is recorded separately. The saved run
reports completion, and \texttt{verification.json} records that every
configuration has both method rows, population MI and margins meet their
checks, rate denominators recalculate, the expanded rejection subset property
holds, and the \(n=1\) setting is explicitly invalid. The separate report
verification checks the display-to-result joins and the existence of its
figures.

The thesis evidence audit goes further. It reconstructs the protocol
manifests, independently selects the exact source configurations for all 22
thesis figures, and checks every numerical result reported in
Chapter~\ref{chap:results}. It also checks the generated LaTeX values, paired
comparisons, convergence ranges, and runtime table against the frozen files.

The supplementary mechanism check is deliberately separate. Its runner is
\path{run_thesis_mechanism_check.py}, and its report generator is
\path{report_thesis_mechanism_check.py}. The saved
\path{results/thesis_mechanism_check/metadata.json} records 809 selected
configurations, 20,000 evaluation pairs per configuration, independent
20,000-pair pilots for 169 nulls, the deterministic seed scheme and hashes of
the frozen source protocol, configuration manifest and population file. The
evidence audit checks its dimensions and the numerical values quoted in
Chapter~\ref{chap:results} and Appendix~\ref{app:mechanism}.

The exact run inputs and software versions are in

Its later changes are confined to atlas-count metadata, saved-output hashes
for future runs, and one-pass handling of a failed preflight; population
construction, simulation and method evaluation are unchanged. All other
recorded input hashes still match the supplied files. The frozen metadata are
retained rather than rewritten after the run. Their figure count of 99 means
primary atlas figures; the later report and preflight records distinguish
these from seven additional calibration zooms, for 106 files in total.

The original run metadata predate per-output hashes. This is not repaired by
altering the historical record. Instead, the package-level hashes in
\texttt{SHA256SUMS.txt} authenticate the delivered archives, while the saved
verification record and evidence audit check the internal result structure,
denominators and reported values. A fresh run with the supplied runner would
also record hashes for the consolidated output tables.

The submitted source and experiment-supplement archives contain the manuscript,
frozen results and generation scripts. Their full names and hashes are recorded
in \texttt{SHA256SUMS.txt}. After extracting both archives into the documented
relative layout, running \texttt{python figures\_rewrite/make\_figures.py}
regenerates the 22 thesis-specific PDFs, figure manifest and numerical macros
without resimulating populations. The manuscript can then be built with
\texttt{latexmk -pdf main.tex}. The archive README records the full audit and
environment commands; no machine-specific installation path is required.

The method's complete scalar runtime does not include construction of the
population probability tables or random count tables. For each timing
regime, 200 saved inputs were prepared; a method had 20 warm-up calls and
five timed passes. Thus the reported microseconds describe this implementation
and machine. Re-running the protocol elsewhere should preserve the
statistical specification and compare statistical outputs before comparing
absolute wall-clock times.
