The companion written atlas is at
\path{WelchSatterthwaiteMI/docs/experiments/THESIS_EXPERIMENTS.md}.
Its 99 primary figures and seven extra calibration zooms retain the full
design. The thesis-specific PDFs in \texttt{Thesis Writeup/Welch MI/
figures\_rewrite/} are generated from the two final CSV files named in the
source script, not from the old pilot folders. The adjacent
\texttt{figure\_manifest.json} lists, for each thesis PDF, its original
section, source files, configuration identifiers and 20,000-replicate
denominator. The file \texttt{evidence\_values.tex} is generated from exact
configuration IDs for the numerical examples in Chapter~\ref{chap:results}.

The plotted rate is \(R^{-1}\sum_s A_{m,s}\), where \(A_{m,s}\) requires
both a valid output and rejection. The method-valid conditional rate divides
valid rejections by that method's valid outputs; it is undefined if there are
none. The common-valid rate restricts to outputs where both methods are
valid. A paired difference is based on counts of the four joint rejection
outcomes for the same table pairs. These distinctions allow a reader to
check whether a curve difference is primarily a changed reference or lost
validity.

Specifically, let \(A_{m,s}\) be the valid-rejection indicator for method
\(m\) on replicate \(s\), and set
\(D_s=A_{\mathrm{expanded},s}-A_{\mathrm{Wald},s}\). The saved paired
difference is \(\bar D=R^{-1}\sum_sD_s\), with approximate 95\% interval
\begin{equation}
  \bar D\ \pm\ 1.96
  \left\{
    \frac{1}{R(R-1)}\sum_{s=1}^{R}(D_s-\bar D)^2
  \right\}^{1/2}.
\end{equation}
This calculation preserves the within-replicate pairing. The individual
method intervals use Wilson's binomial score construction
\citep{wilson1927}.

For any \(P\) population with sample size \(n_P\), its minimum expected
cell count is \(\min_{ij}n_Pp_{ij}\); define \(Q\)'s analogously. No
``expected minimum'' of random observed counts is calculated. The saved
support diagnostics include empty observed rows and columns and the fraction
of zero-count cells. Such values describe why a statistic might fail, but
do not constitute a universal validity threshold.

The thesis does not treat a descriptive count of regimes closer to 0.05 as
a formal paired test over regimes. Wilson intervals quantify binomial Monte
Carlo variation at each fixed point, and paired normal intervals quantify a
specified within-configuration method difference. Neither interval family is
a simultaneous assertion across all configurations. Tables sharing a
population but changing \(n\) or \(|\Delta|\) answer different fixed-design
questions and should not be collapsed into one mean rate.
