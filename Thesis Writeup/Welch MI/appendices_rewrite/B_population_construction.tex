\chapter{Population Construction and Exact Design Settings}
\label{app:construction}

The experiment uses fixed population tables. This appendix states the
construction precisely enough to reproduce any plotted point and records the
finite parameter grids. Full-precision probabilities for every constructed
pair are stored in \texttt{population\_definitions.csv}; rounded examples in
the thesis are for reading, not simulation input.

\section{Additive construction}

For prescribed positive row vector \(a\) and column vector \(b\), form
\(B=ab^{\mathsf T}\). The principal first-cell direction \(H\) contains
\(\left(\begin{smallmatrix}1&-1\\-1&1\end{smallmatrix}\right)\) in
rows and columns 1 and 2 and zero elsewhere. The rare-cell direction places
the same block in the last two rows and columns. The spread direction is
\begin{equation}
 H_{ij}=u_i v_j,
 \quad u_i=-1+\frac{2(i-1)}{r-1},
 \quad v_j=-1+\frac{2(j-1)}{c-1}.
 \label{eq:appendix-spread}
\end{equation}
Both score vectors sum to zero, so every direction preserves margins.

For \(t\ge0\), define \(R(t)=B+tH\). Calculate the first strength at which
a decreasing cell reaches zero,
\begin{equation}
 t_{\max}=\min_{H_{ij}<0}\frac{B_{ij}}{-H_{ij}}.
\end{equation}
Evaluate the path endpoint MI\@. A target MI must lie strictly below this
endpoint, within the stated numerical tolerance. For a positive target,
Brent's one-dimensional root search \citep{brent1973} solves \(I\{R(t)\}=I_{\rm target}\)
on \([0,t_{\max}]\); a zero target uses \(t=0\). The final table is accepted
only if every cell is strictly positive, the sum is one, both margins agree
with their prescribed vectors, and achieved MI agrees with the target. The
normalisation and margin tolerances are \(10^{-12}\); the MI tolerance is
\(10^{-12}+10^{-8}I_{\rm target}\). These numerical checks ensure that a
horizontal-axis difference denotes constructed population truth, not an
empirical estimate. They do not impose an expected-count floor on the
subsequent sample.

The row and column vectors are separately constructed for each population.
For shape \(r\times c\), profile \texttt{uniform} uses uniform vectors of
lengths \(r\) and \(c\) for both \(P\) and \(Q\). Profile
\texttt{same\_skew} uses \(m_r(0.8)\), \(m_c(0.8)\) for both. Profile
\texttt{different\_skew} uses \(m_r(0.7)\), \(m_c(0.7)\) for \(P\) and
\(m_r(0.8)\), \(m_c(0.8)\) for \(Q\). The extreme regimes instead state the
two dominant probabilities directly. The direction of the alternative is a
separate parameter and should not be inferred from which population has the
more skewed margin.

The log-linear comparison uses an ordinal interaction pattern. Its strength
is tuned numerically while iterative proportional fitting \citep{deming1940} preserves the
given row and column margins. The final table is subjected to the same
positivity, normalisation, margin and target-MI checks as the additive table.
This is a comparison across two ways to make plausible fixed populations,
not a claim that a matched target implies matched higher moments or cell
counts.

\section{Frozen statistical grids}

Unless a row of Table~\ref{tab:exact-grids} says otherwise, both populations
use the first-cell additive direction, \(I(P)=I_0\),
\(I(Q)=I_0+|\Delta|\), and the three standard margin profiles. The
symbol \(n\) means \(n_P=n_Q=n\). A requested point was simulated only after
the population constructor verified a strictly positive feasible table.
The final display contains no infeasible slots, but that is a result of
choosing feasible finite grids, not permission to extend any curve beyond
its last constructed target.

The \(n=1\) stress setting is retained and not hidden; the statistic is
not evaluable there and its result is recorded as invalid. Every unique
statistical configuration has 20,000 sampled table pairs. When the same
population pair and sample sizes appear in another section, the saved
configuration is reused for presentation and not simulated again.
