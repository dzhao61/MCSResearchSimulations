# Archived Experiment Documents

These documents record investigated approaches that are no longer part of the
active constrained likelihood-ratio validation path.

- [Welch critical-value audit](WELCH_CRITICAL_VALUE_AUDIT.md) diagnoses why a
  different Student critical value does not provide a general correction.
- [Joint Cornish-Fisher no-go study](JOINT_CORNISH_FISHER_NO_GO.md) records the
  unsuccessful higher-order correction and the evidence for discontinuing it.

They are retained for reproducibility and research provenance.
