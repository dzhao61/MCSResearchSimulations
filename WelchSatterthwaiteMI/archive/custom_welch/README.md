# Archived Custom Welch Study

This directory preserves the discontinued Custom Welch routing experiment.
The proposal selected between normal Wald and expanded Welch using a
sample-size-ratio rule. It was removed from the active thesis method because
the additional routing layer complicated the method and its supported domain.

The archive contains:

- `CUSTOM_WELCH_DECISION_AUDIT.md`: rationale, experiment, and conclusions;
- `investigate_custom_welch_decision.py`: reproducible audit script;
- `results/`: complete generated CSV files, report, metadata, and plot.

These materials are historical evidence only. The active project compares
normal Wald, simple Welch-Satterthwaite, and expanded
Welch-Satterthwaite directly.
